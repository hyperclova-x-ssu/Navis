# PN14 virtual CLOVA Studio

[Chat Completions v3](https://api.ncloud-docs.com/docs/clovastudio-chatcompletionsv3) defines the
HCX-005 request and response fields. The virtual server's model output is deterministic synthetic text.
An explicit review-reply draft request uses the scoped review text, rating, style and length to
produce an editable acknowledgment. The fixture does not repeat raw review text or insert promises,
discounts or unverified facts. The regular fallback still handles other ordinary text prompts.
