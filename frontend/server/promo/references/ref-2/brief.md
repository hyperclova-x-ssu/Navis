출처: PROMO_TEMPLATES 2.2. 카드 1:1, 대표 장면 `s2`. 어울림: 따뜻한·깔끔한 / 리뷰 모음·신메뉴 소개.

## 느낌의 핵심 5가지 (지킬 것)
1. 밝고 깔끔한 단색 바탕(따뜻하면 #F7F3EE, 깔끔하면 #F4F6F8)
2. 사진은 둥근 카드(위쪽 70%, y 120부터 높이 약 1300까지, 모서리 반지름 48)
3. 말풍선이 하나씩 올라옴(220ms, 사이 0.6초), 꼬리 없는 둥근 말풍선(흰 면 + 얇은 선)
4. 사진에 보이는 것(맛·모양·재료·가격표 글자)만 짧게 칭찬하는 한 줄. 손님이 한 말처럼 따옴표 쓰지 않음
5. 말풍선 안 핵심 단어 하나만 굵게 + 연한 초록 면(#E4F6EA, 글자 #006E38)
