# ref-6 손글씨 감성 카드 (디자인 기준)

출처: PROMO_TEMPLATES 2.6. 카드 1:1, 대표 장면 `s2`. 어울림: 따뜻한·고급스러운 / 리뷰 모음·오늘의 할인.

## 느낌의 핵심 5가지 (지킬 것)
1. 크림색 종이 바탕 #F7F3EE
2. 폴라로이드 카드: 흰 면, 위·좌·우 여백 36, 아래 여백 120(손글씨 한 줄 자리), 그림자 0 8 24 rgba(0,0,0,.18), 크기 폭 760×높이 1000
3. 살짝 기운 각도: 장면마다 -3°~+3° 번갈아. 카드가 위에서 떨어지며 자리 잡음(`drop-in`: translateY -120→0, 회전 6°→목표 각, 320ms, 한 번만 약한 감속). 이전 카드는 뒤에 쌓여 최대 3장(사진이 그 장면 밖에 보이지 않게, 뒤 카드는 빈 종이 카드로 보여도 됨)
4. 손글씨 느낌 한 줄: 손글씨 글꼴이 없으므로 `Navis Sans` 700 + 종이 카드 모양으로 느낌을 냄. 카드 아래 여백 안 1줄 56px(ko 12자까지, 역할 `cap`). 훅 카드는 2줄 × 10자, 크기 80(역할 `title`)
5. 노랑 형광펜 한 단어: 자막 중 한 단어 뒤에 #FFF2CC 면, 글자 #1E1E23. 색 글자 없음. 마스킹 테이프 장식 한 장(#FFD400 60%, 모서리 위 12°)

## 구성
s1 훅 카드(외관 폴라로이드 + 손글씨 훅 2줄) → 카드 장면들(사진 폴라로이드 + 아래 여백 한 줄) → 엔딩(크림 바탕, 가게 이름 `Navis Serif`, 손글씨 한 줄 문구, 위치 sub, 모서리 테이프).
사진 `kenburns` 없음(카드 자체가 정적). 말은 한 줄 속삭임 톤.

## 길이별 기준 예시(초, [자유])
| 길이 | 훅 카드 | 카드 장면 | 엔딩 | 사진 자리 |
| :--- | :--- | :--- | :--- | :--- |
| 10 | 0~2 | 2~4.5 closeup · 4.5~7.5 table | 7.5~10 | closeup, table + 외관 |
| 15 | 0~3 | 3~6 closeup · 6~9 table · 9~12 inhand | 12~15 | closeup, table, inhand + 외관 |
| 30 | 0~3 | 카드 6장 각 약 3.8 (재사용 규칙) | 26~30 | 5장 + 외관 |

## 다르게 만들 것
카드 각도·겹침, 테이프 위치, 형광펜 단어, 한 줄 문장, 훅 문장은 분위기·컨셉·메모에 맞춰 매번 새로. 카드 두 번 떨어지는 사이 2.5초 이상 멈춘 구간이 길지 않게.
