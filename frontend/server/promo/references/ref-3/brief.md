# ref-3 진열대 천천히 훑기 (디자인 기준)

출처: PROMO_TEMPLATES 2.3. 카드 4:5, 대표 장면 `s2`. 어울림: 고급스러운·깔끔한 / 신메뉴 소개·우리 가게 하루.

## 느낌의 핵심 5가지 (지킬 것)
1. 느린 호흡: 사진 장면은 2.5초 이상(시작 외관 장면만 1~2초 허용)
2. 사진이 프레임 전체를 채움
3. 카메라가 천천히 가로로 지나감: 일정한 속도(easing 없음)의 `pan`(이동 ≤ 18%), 확대 1.00→1.04, 장면마다 방향을 번갈아
4. 아래 작은 한 줄 자막만: y 1460~1560 근처 `sub` 48 한 줄(18자), 검정 55% 띠(높이 160) 위, 장면당 0~1개, 장면 시작 뒤 늦게 400ms 페이드로 등장. 첫 단어(메뉴 이름) 800, 나머지 500, 색 강조 없음
5. 어두운 엔딩: 흐린 외관 + 어두운 면 55%, 가게 이름 `Navis Serif` 흰색(자간 .08em), 가는 선 120폭, 한 줄 문구, 위치(회색 #D9D9D9)

## 움직임
장면 전환은 600ms 크로스페이드. 사진이 세로보다 가로가 길면 높이를 1920에 맞추고 가로로 훑는다. 번쩍임 없음.

## 다르게 만들 것
훑는 방향·속도, 어떤 사진에 자막을 둘지, 자막 문장, 엔딩 한 줄 문구는 분위기·컨셉·메모에 맞춰 매번 새로. 장면 수는 범위 안에서 바꿔도 된다.
