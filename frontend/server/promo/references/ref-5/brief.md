# ref-5 우리 가게 하루 타임라인 (디자인 기준)

출처: PROMO_TEMPLATES 2.5. 카드 4:5, 대표 장면 `s3`. 어울림: 따뜻한·깔끔한 / 우리 가게 하루·만드는 과정.

## 느낌의 핵심 5가지 (지킬 것)
1. 시간대가 흐름: 아침 → 점심 → 오후 → 저녁. 시각 숫자 대신 **시간대 이름**(왼쪽 위 꼬리표, `label` 36, 700~800)
2. 사진 한 장을 가운데 카드로(폭 840, 높이 1100, 반지름 32, y 300~1400), 카드가 오른쪽에서 들어옴(`slide-in` 280ms)
3. 시간대마다 배경색: 아침 #FFF2CC, 점심 #FFFFFF, 오후 #FBEAED, 저녁 #EAF0FC
4. 세로 타임라인 선(왼쪽 가장자리 x=84): 점 3~4개를 잇는 선이 장면마다 한 칸씩 채워짐(240ms), 현재 시간대만 진하게
5. 지어낸 시각·사실 없음: 사진에 보이지 않는 시각·영업시간·사실을 쓰지 않는다. 시간대는 장면 순서의 연출

## 구성
s1 시작(외관 카드 + “아침”) → 시간대 장면들(사진 카드 + 아래 y 1460~1560 `cap` 64 한 줄 14자) → 엔딩(마지막 시간대 배경 위 가게 이름 `Navis Serif` 어두운 글자, 한 줄 문구, 위치, 작은 외관 카드).
사진 순서: 외관(오전 시작) → 진열·만드는 과정 → 손님·차림·마감 느낌 순으로 놓는다.

## 움직임
카드 교체 280ms(옆에서 들어옴), 사진 `kenburns` 1.00→1.05, 배경색은 장면 전환과 함께 한 번만 바뀜(번쩍임 없음).

## 다르게 만들 것
카드 들어오는 방향, 꼬리표 모양, 자막 문장, 시간대 수(3~5), 엔딩 문구는 매번 새로.
