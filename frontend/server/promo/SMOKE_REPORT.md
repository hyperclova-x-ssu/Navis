3. **빈 장면·정지 → 사라짐.** 엔딩 말고 글자 없는 컷 없음(장면 첫 0.3초 전환 직후 제외). a-ref4 1~3컷은 같은 장면(0~3초)이지만 사진이 계속 확대되어 정지가 아님(검사 `scene.still` 통과).
4. **크로스페이드 중 겹침 → 글자 겹침은 사라짐.** a-ref2 3·9컷(2.5·8.5초)은 정확히 장면 경계라 사진 두 장이 0.3초 페이드 중으로 섞여 보이지만 글자는 한 장면 것만(들어오는 장면 글자는 전환 뒤에 나옴). 전환 길이는 계약 상한 0.4초 안.
   - 참고: 처음 만든 프레임 모음(`-ss 0.5` + `fps=1`)은 실제로 각 초의 0.95초 근처(=장면 경계 직전)를 뽑아 모든 경계 컷이 반투명하게 보였음. T-086 4절의 문제 4 사례(a-ref2 5컷·d-1 5컷·a-ref3 7컷)도 같은 방식이었다면 일부는 프레임 시각 때문일 수 있음. 이번 모음은 프레임 번호로 정확히 뽑음.

## 3. 새로 발견해 고친 결함

- **한글 깨짐(U+FFFD)**: a-ref1 장면 구성의 말풍선이 “초콜릿 올라�� 마지막 하나”로 나옴. 원인: `claude-runner.mjs`가 stdout 조각(Buffer)을 조각마다 문자열로 이어 붙여, 조각 경계에 걸친 한글 한 글자가 깨짐. 고침: 조각을 모아 `Buffer.concat(...).toString('utf8')`. 시험(`runner.test.mjs` 조각 경계 시험) 추가, 글자 검사기 `text.control`이 U+FFFD도 잡아 다시 쓰기로 보냄. 이 영상(a-ref1)은 고치기 전 생성이라 깨진 글자가 남아 있음(재생성은 하지 않음 — 한도 4편).

## 4. 바뀐 규칙 요약 (rules.json v2, 계약 v2)

| 규칙 | 단계 | 내용 |
| :--- | :--- | :--- |
| `story.photoFit` | 이야기 | 품절·다 사 갔다 → `amount` many 사진 금지 / 남은 수량(외관만 있는 장면 제외) → `menuShown` main·`amount`≠none / 메뉴 이름을 말하는 장면 1개짜리 자막(말풍선 제외) → 그 메뉴로 등록되고 `menuShown`≠no |
| `story.sceneText` | 이야기 | 엔딩 아닌 장면에 글자 0개면 1.5초 이하만 |
| `text.overlap` | 장면 검사 | 글자끼리 줄 상자 15% 이상 겹침, 사진(`data-photo`, 화면 전체 층 제외)이 글자의 15% 이상 가림 — actual에 시각·상자 위치 |
| `transition.text` | 장면 검사 | `sceneIds`가 겹치지 않는 두 글자가 같은 순간에 보임 |
| `transition.length` | 장면 검사 | 이웃 두 장면이 함께 보이며 한쪽이 반투명한 시간 > 0.4초(경계 ±0.6초, 0.05초 간격) |
| `scene.still` | 장면 검사 | 화면 서명이 1.5초 이상 같음(엔딩 제외) |
| `scene.empty` | 장면 검사 | 장면 동안 글자 0개이고 움직임 < 24px |
